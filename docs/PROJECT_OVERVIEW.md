# Project Overview

## Goal

Evaluate whether commonly proposed EEG biomarkers for Alzheimer’s disease are methodologically robust, disease-specific, clinically meaningful, and measurable with a reduced electrode montage.

## Why this project matters

Many dementia EEG studies report strong differences in spectral power and functional connectivity. However, a biomarker can appear useful for several reasons that do not necessarily imply disease-specific neurophysiology. Examples include fixed frequency bands despite alpha slowing, compositional effects from relative power, aperiodic spectral changes, volume conduction in coherence, EEG referencing choices, and weak validation design.

This project therefore separates **replication**, **critique**, **prediction**, and **engineering optimization**.

## Four project stages

### Stage A — Reproduce
Reproduce the DICE-style Relative Band Power (RBP) and Spectral Coherence Connectivity (SCC) analysis as closely as practical.

### Stage B — Challenge
Test whether the apparent biomarkers remain stable under alternative spectral and connectivity methods.

### Stage C — Predict
Compare biomarker families using identical subject-level machine-learning pipelines.

### Stage D — Engineer
Determine the smallest electrode subset that retains both predictive performance and biologically meaningful biomarker information.

## Primary output

The desired final result is not simply the highest classification accuracy. The target is a defensible answer to:

> Which EEG biomarkers remain useful after methodological stress testing, and how few electrodes are required to retain them?
