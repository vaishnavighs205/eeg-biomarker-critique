# Roadmap

## Milestone 1 — Dataset and QC

Deliverables:

- all expected participants matched to metadata
- channel and sampling-rate verification
- duration table
- QC flags
- example raw trace and PSD
- group counts

Exit criterion: no unresolved subject/file mismatch.

## Milestone 2 — DICE replication

Deliverables:

- RBP feature table
- SCC feature table
- AD vs CN statistical comparison
- scalp maps / connectivity visualization
- baseline subject-level ML results

Exit criterion: reproduction pipeline is internally consistent and documented.

## Milestone 3 — Spectral critique

Deliverables:

- absolute vs relative power comparison
- IAF estimates and validity rate
- fixed vs individualized bands
- periodic/aperiodic decomposition
- revised spectral biomarkers

## Milestone 4 — Connectivity critique

Deliverables:

- SCC
- wPLI
- imaginary coherence
- reference-sensitivity analysis
- connectivity-method comparison

## Milestone 5 — Specificity and severity

Deliverables:

- AD vs CN
- FTD vs CN
- AD vs FTD
- MMSE correlations
- demographic sensitivity models

## Milestone 6 — ML biomarker comparison

Deliverables:

- identical nested CV across feature families
- subject-level performance table
- ablation analysis
- uncertainty/fold distributions

## Milestone 7 — Robust biomarker decision

Deliverables:

- biomarker robustness matrix
- final feature families that advance to electrode optimization

## Milestone 8 — Minimal electrodes

Deliverables:

- nested channel selection
- performance vs channel-count curve
- biomarker-preservation vs channel-count curve
- candidate practical montage

## Milestone 9 — Final research package

Deliverables:

- final figures and tables
- reproducible config
- cleaned README
- methods document
- limitations
- presentation/poster/paper-ready results
