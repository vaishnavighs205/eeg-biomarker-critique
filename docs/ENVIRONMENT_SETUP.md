# Development Environment Setup

This guide explains how to configure the Python environment required to work on the EEG Biomarker Critique project.

## Requirements

Before starting, install:

- Git
- Conda or Miniconda
- GitHub CLI (recommended)
- DataLad
- git-annex

The project uses:

- Python 3.11
- MNE-Python
- NumPy
- SciPy
- pandas
- scikit-learn
- statsmodels
- specparam
- MNE-Connectivity
- XGBoost
